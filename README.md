# Adidas US sales Analysis . 
Project Overview : this project analyzes adidas us sales data 2020 & 2021 to evaluate sales performance, profitability, product performance, retailer contribution and regional trends. 
Tools & Skills : Microsoft excel , data cleaning using power query , data normalization , time intelligence using calendar table , data modeling and make connection between data table and calendar table using power pivot , pivot tables , pivot charts , KPI analysis , sales and profits analysis and data visualization using dynamic dashboard and slicers . 
Key analysis : the analysis covers >> total sales and revenue , total profit , sales by retailer , sales by product , sales by region , sales by state , sales by city , sales by sales method , sales trends overtime .
